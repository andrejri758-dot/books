# Конспект проєкту Book Haven

Цей документ простими словами пояснює, як улаштований сайт і що було зроблено для його SEO.

## Що це за сайт

Book Haven — англомовна сторінка з добіркою книжок. Вона показує назву й обкладинку книжки, автора, жанри та кнопки для пошуку, кошика й підписки.

## З яких файлів складається сайт

- **`index.html`** — головна сторінка, яку відкриває GitHub Pages. У ній є назва сторінки, SEO-дані та підключення стилів і JavaScript.
- **`64.html`** — ще одна HTML-сторінка сайту з такими самими SEO-налаштуваннями.
- **`64.ls/64.js`** — код, який створює вміст сторінки: список книжок, заголовки, фільтри й інші елементи.
- **`64.css/64.css`** — вигляд сайту: кольори, розташування блоків і пристосування сторінки до різних розмірів екрана.
- **`64.js/64.img/`** — зображення та іконка сайту.
- **`robots.txt`** — повідомляє пошуковим роботам, що сторінку можна переглядати, і вказує на карту сайту.
- **`sitemap.xml`** — карта з адресою головної сторінки, яка допомагає пошуковикам її знаходити.
- **`.github/workflows/deploy.yml`** — автоматична публікація сайту на GitHub Pages після змін у гілці `64-site`.
- **`README.md`** — короткий опис проєкту та публікації.

## Що означають SEO-налаштування

SEO — це підготовка сторінки, щоб пошуковим системам було легше зрозуміти її зміст, а посилання на неї краще виглядало в пошуку та соціальних мережах.

У `index.html` і `64.html` додано:

- **`<title>`** — назва сторінки, яку зазвичай показує вкладка браузера та пошукова видача.
- **`description`** — короткий опис сайту для пошукової видачі.
- **`canonical`** — основна адреса сайту. Вона підказує пошуковикам, яку адресу вважати головною.
- **Open Graph** — назва й опис для попереднього перегляду посилання в соцмережах і месенджерах.
- **Twitter Card** — назва формату та текст для попереднього перегляду посилання у X.
- **Schema.org у форматі JSON-LD** — структурований опис сайту, який пошуковику простіше прочитати, ніж звичайний текст.
- **`robots`** — дозволяє пошуковим роботам індексувати сторінку та переходити за її посиланнями.
- **`theme-color`** — колір елементів браузера на сумісних пристроях; на позицію в пошуку не впливає.

## Що покращено у вмісті сторінки

У `64.ls/64.js`:

- Додано один головний заголовок `h1`, який коротко пояснює тему сторінки.
- Книжки оформлено окремими статтями з назвою `h2`, автором і зображенням.
- Додано змістовний альтернативний текст зображень. Його можуть прочитати програми екранного доступу; він також пояснює зображення, якщо воно не завантажилося.
- Для більшості обкладинок увімкнено відкладене завантаження. Браузер завантажує їх ближче до моменту, коли відвідувач прокручує до них сторінку.
- Додано зрозумілі назви областей для навігації, пошуку, фільтрів і форм. Це допомагає доступності та полегшує розуміння структури сторінки.

У `64.css/64.css` змінено оформлення посилань-логотипів, щоб вони зберігали стиль сайту, а не виглядали як стандартні підкреслені посилання.

## Як сайт працює

HTML-файл завантажує React і Babel із зовнішньої CDN. JavaScript у `64.ls/64.js` використовує React, щоб намалювати список книжок у браузері, а CSS додає оформлення.

Важливо: поле пошуку, жанрові прапорці та кнопки кошика й підписки зараз показані на сторінці, але не підключені до справжньої логіки пошуку, замовлення чи надсилання даних.

## Публікація змін

Сайт публікується з гілки `64-site`. Щоб опублікувати зміни через PowerShell:

```powershell
git add .
git commit -m "Describe your changes"
git push origin 64-site
```

Після `git push` GitHub Actions запускає процес публікації. Коли він завершиться, сайт доступний за адресою:

<https://andrejri758-dot.github.io/books/>

Додані SEO-дані полегшують пошуковим системам розуміння сайту, але самі по собі не гарантують появу в результатах пошуку чи високу позицію. Для індексації потрібен час, а частина вмісту сайту створюється JavaScript уже в браузері.
